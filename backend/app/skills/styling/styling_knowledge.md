# 衣渐佳 Styling Knowledge

Version: 0.1

本文件为衣渐佳 AI 造型师提供稳定的基础穿搭知识。

这些内容属于启发式原则，而非绝对规则。

最终建议必须同时考虑：

- 用户明确约束
- 使用场景
- 已有单品
- 舒适性
- 用户偏好
- 当前 Look 的整体关系

用户明确约束始终优先于一般穿搭原则。


---

# 1. Color Harmony｜色彩协调

## 1.1 配色判断

判断整体配色时优先观察：

1. 是否存在明确主色
2. 全身主要颜色是否过多
3. 明度是否形成合理层次
4. 饱和度是否彼此协调
5. 是否有视觉重点
6. 鞋、包、配饰是否与主体产生联系

颜色不需要完全一致。

协调不等于所有单品都使用同一种颜色。


## 1.2 Neutral Colors｜中性色

常见中性色包括：

- 黑
- 白
- 灰
- 米白
- 卡其
- 棕
- Navy
- Denim Blue

中性色适合构建稳定基础。

常用于：

- 通勤
- 面试
- 日常
- 简约风

如果全身都是相似中性色，同时缺乏材质、明度或廓形差异，
整体可能协调但缺少视觉重点。

此时优先考虑：

- 深浅变化
- 材质变化
- 小面积强调色
- 一个配饰

而不是一次加入多个复杂元素。


---

# 2. Color Recipes｜常见配色策略

以下属于优先候选，而不是强制搭配。

## 2.1 黑色

稳定组合：

- 黑 + 白
- 黑 + 灰
- 黑 + 米白
- 黑 + Denim Blue
- 黑 + Navy

增加风格表现：

- 黑 + Burgundy
- 黑 + Forest Green
- 黑 + Cobalt Blue
- 黑 + Silver


## 2.2 灰色

稳定组合：

- 灰 + 白
- 灰 + 黑
- 灰 + Navy
- 灰 + 米白

柔和方向：

- 灰 + Dusty Blue
- 灰 + Muted Pink
- 灰 + Cream

强调色：

- 灰 + Burgundy
- 灰 + Cobalt Blue
- 灰 + Forest Green


## 2.3 Denim Blue

稳定组合：

- Denim + 白
- Denim + 黑
- Denim + 灰
- Denim + Navy

温暖方向：

- Denim + Cream
- Denim + Camel
- Denim + Brown

强调方向：

- Denim + Red
- Denim + Burgundy
- Denim + Green


## 2.4 Brown / Camel

常见协调方向：

- Brown + Cream
- Brown + Beige
- Brown + White
- Brown + Denim
- Brown + Olive
- Brown + Burgundy

棕色通常适合构建偏温暖、复古或自然的视觉氛围。


---

# 3. Accent Color｜强调色

一个稳定策略是：

Neutral Base + Small Accent

例如：

- 黑 + 灰 + 酒红包
- 白 + Denim + 红色小配饰
- 米白 + 棕 + 绿色配饰
- Navy + White + Burgundy

如果用户希望“更有风格”，
优先尝试小面积强调色，
而不是直接替换多个核心单品。

避免在没有明确风格目标时，
同时使用多个高饱和强调色。


---

# 4. Monochromatic｜同色系

同色系不意味着完全同一个颜色。

可以通过：

- 明度
- 深浅
- 饱和度
- 材质

制造层次。

例如：

- Cream + Beige + Brown
- Light Gray + Gray + Charcoal
- Light Blue + Denim + Navy

如果颜色非常接近，
应更多关注材质和廓形层次。


---

# 5. Color Echo｜色彩呼应

鞋、包、首饰或小面积服装元素之间出现相近颜色，
可以增加整体完整度。

例如：

- Brown Belt + Brown Shoes
- Burgundy Bag + Burgundy Detail
- Silver Shoes + Silver Jewelry

色彩呼应是加分项，
不是必须满足的规则。

避免为了“呼应”而机械增加多余配饰。


---

# 6. Pattern｜图案

当一个核心单品已经具有明显：

- 条纹
- 格纹
- 花纹
- Graphic
- 大 Logo

其他大面积单品通常可以适当简化。

例如：

条纹衬衫 + 纯色裤子

通常比：

条纹衬衫 + 大格纹裤子

更容易保持视觉层级。

多个图案同时存在时，需要考虑：

- 图案尺度是否有区别
- 是否存在共同颜色
- 是否有明确主角

不得简单使用“图案不能搭图案”的绝对规则。


---

# 7. Proportion｜比例

比例判断不能机械套用“上短下长”。

需要综合观察：

- 腰线位置
- 上衣长度
- 下装腰线
- 裤长 / 裙长
- 鞋型
- 上下装视觉重量
- 用户希望呈现的风格


## 7.1 腰线

如果：

- 上衣较长
- 下装较宽
- 上下视觉重量都较大

且用户希望更利落，

可以考虑：

- 半塞 / 全塞上衣
- 缩短上衣视觉长度
- 强化腰线
- 调整外套长度

但是：

如果用户明确追求 relaxed / oversized 风格，
不应强行要求突出腰线。


## 7.2 上短下长

短上衣 + 较高腰下装
通常容易形成更明显的纵向比例。

但必须同时考虑：

- 场景
- 用户舒适程度
- 上衣实际长度
- 下装腰线
- 是否符合用户风格

不能把“越短越好”作为规则。


---

# 8. Silhouette｜廓形

常见廓形：

- fitted
- straight
- relaxed
- oversized
- wide
- flared
- A-line

廓形判断重点是：

- 是否有视觉结构
- 上下量感是否有意图
- 腰线是否需要出现
- 材质是否有垂坠感
- 是否符合当前风格


## 8.1 上宽 + 下窄

通常能形成明显上下量感对比。

例如：

Oversized Top
+
Straight / Slim Bottom

通常较容易形成明确结构。


## 8.2 上窄 + 下宽

例如：

Fitted / Cropped Top
+
Wide-leg Pants

通常容易形成清晰比例。


## 8.3 上宽 + 下宽

不能直接判定错误。

如果：

- 长度关系明确
- 面料垂坠
- 鞋型能够承接视觉重量
- 用户明确追求 relaxed / oversized

完全可以成立。

如果整体显得缺少结构，
可以优先考虑：

1. 调整腰线
2. 改变其中一件视觉长度
3. 调整鞋型
4. 降低一个单品的视觉重量

而不是立刻替换整套衣服。


---

# 9. Length Relationship｜长短关系

判断长度主要观察：

- 上衣落点
- 外套落点
- 裤脚 / 裙摆
- 鞋面关系
- 多层衣服之间是否产生清晰层级

当多个单品边缘集中在相似位置时，
可能造成视觉切割。

可尝试：

- 调整上衣塞法
- 改变外套长度
- 调整裤脚
- 使用不同鞋型

但应结合整体风格判断。


---

# 10. Visual Focus｜视觉重点

一套 Look 不一定需要多个亮点。

视觉重点可能来自：

- 颜色
- 图案
- 廓形
- 鞋
- 包
- 首饰
- 材质
- 层次

如果整套都是：

基础色
+
基础款
+
相似材质

整体可能协调但缺少记忆点。

如果用户希望“更出彩”，
优先增加一个明确变化。

不要同时加入多个抢眼元素。


---

# 11. Texture｜材质

颜色接近时，
不同材质可以帮助建立视觉层次。

例如：

- Knit + Denim
- Wool + Leather
- Cotton + Structured Bag
- Satin + Knit

材质对比应服务整体风格。

不应因为追求层次而使用明显不符合季节或场合的材质。


---

# 12. Layering｜叠穿

叠穿可以用于：

- 增加层次
- 调节季节适应性
- 改变正式度
- 增强造型结构

常见组合：

- T-shirt + Shirt
- Shirt + Knit
- Inner Top + Blazer
- Dress + Jacket

需要注意：

- 领口关系
- 长度关系
- 上下视觉重量
- 色彩数量

如果多层单品都非常宽大，
需要特别检查整体是否失去结构。


---

# 13. Accessories｜配饰

配饰通常用于：

- 增加视觉重点
- 调整正式程度
- 增强风格表达
- 形成色彩呼应
- 提升完整度

包括：

- 包
- 腰带
- 帽子
- 耳饰
- 项链
- 手表
- 丝巾
- 袜子

原则：

优先增加一个高价值配饰。

不要因为“更出彩”就默认加入多个配饰。

用户明确表示没有配饰时，
不得把新增配饰作为必要条件。


---

# 14. Shoes｜鞋型

鞋会同时影响：

- 风格
- 正式程度
- 下半身视觉重量
- 使用场景
- 舒适程度

选择鞋型时必须考虑用户功能约束。

例如：

用户说：

“今天需要走很多路”

舒适性应优先于纯视觉优化。

用户说：

“不穿高跟鞋”

不得为了显高、正式或女性化再次推荐高跟鞋。


---

# 15. Occasion｜场景

推荐不能只追求“更时髦”。

需要优先满足场合底线。

可粗略理解为：

Level 1
居家 / 极休闲

Level 2
日常 / 逛街 / 旅行

Level 3
普通通勤 / 约会 / 聚餐

Level 4
面试 / 见客户 / Business Casual

Level 5
正式商务 / 仪式场合

正式程度判断仍需结合用户提供的具体环境，
不能只依赖一个标签。


---

# 16. Minimal Intervention｜最小干预

对于“这身怎么改”，
优先考虑低成本、高收益修改。

通常可以按照：

1. 调整穿法
2. 调整腰线
3. 袖口 / 裤脚调整
4. 调整鞋型
5. 替换一件核心单品
6. 增加一个配饰
7. 替换多个核心单品

的顺序考虑。

这不是机械流程。

如果核心问题明显来自某一件单品，
可以直接提出单件替换。


---

# 17. Keep What Works｜保留已经正确的部分

穿搭诊断首先需要识别：

“当前哪些部分已经是合理的？”

例如：

- 配色已经协调
- 裤型已经适合当前上衣
- 鞋子已经符合场景

这些内容应明确进入 keep_items。

不要为了制造 Before / After 对比，
把已经合理的部分也全部改掉。


---

# 18. Stop Rule｜停止继续优化

如果当前 Look 已经满足：

- 配色协调
- 比例合理
- 廓形关系有意图
- 风格一致
- 场景适配
- 已经有足够视觉重点

则可以直接告诉用户：

“目前已经比较完整，不建议为了增加复杂度继续加配饰或替换单品。”

AI需要具备“不修改”的能力。


---

# 19. User Preference｜个人偏好

通用造型规则不能覆盖用户明确偏好。

例如：

用户长期偏爱：

- 简约
- 黑白灰
- 平底鞋

那么在没有明确需求时，
推荐可以优先从这些方向开始。

但用户当前说：

“今天想尝试一点颜色”

当前 Session Goal 应优先于历史偏好。


---

# 20. Knowledge Boundaries｜知识边界

不得使用：

“梨形身材绝对不能穿……”

“黄皮不能穿……”

“矮个子不能穿……”

“这样一定显胖……”

等绝对化表达。

更合适的方式：

“如果你的目标是让整体比例更利落，可以尝试……”

“在当前这套 Look 中，这个长度可能让上下分界不够明确，可以考虑……”

所有建议应基于当前 Look 和用户目标，
而不是给用户贴固定标签。
